Guías de soporte IT N1

Base de conocimiento con los problemas más habituales de un Service Desk de nivel 1, escrita para equipos Windows 10/11 con Microsoft 365 en un entorno de oficina. Cada guía sigue el mismo esquema: síntomas, preguntas al usuario, comprobaciones, diagnóstico, solución, cuándo escalar a nivel 2, qué anotar en el ticket y prevención.

Cuando encaja, se indica qué opción de mi herramienta IT Support Toolkit usar, junto con la alternativa manual de Windows. Según Microsoft, el soporte técnico de Windows 10 finalizó el 14 de octubre de 2025; por eso las guías indican también los pasos de Windows 11.

Red

  • No tengo conexión a Internet

    Prioridad alta 10–20 min

  • Tengo red pero no cargan las páginas web (DNS)

    Prioridad alta 10–20 min

  • El Wi-Fi se desconecta o va lento

    Prioridad media 15–30 min

Hardware y periféricos

  • La impresora no imprime

    Prioridad media 10–25 min

  • No se escucha el sonido

    Prioridad baja 5–15 min

  • No detecta el segundo monitor

    Prioridad baja 10–20 min

Sistema

  • El equipo va lento

    Prioridad media 15–30 min

  • El disco está lleno

    Prioridad media 10–25 min

  • Un programa no se abre o se cierra solo

    Prioridad media 10–25 min

Cuentas y correo

  • He olvidado mi contraseña o tengo la cuenta bloqueada

    Prioridad alta 5–15 min

  • Outlook no envía ni recibe correos

    Prioridad alta 15–30 min

Seguridad

  • He recibido un correo sospechoso (phishing)

    Prioridad alta 5–15 min
